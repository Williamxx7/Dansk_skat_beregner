# Dansk skatteberegner

En enkel skatteberegner i ren HTML, CSS og JavaScript.

**Live:** https://williamxx7.github.io/Dansk_skat_beregner/

## Funktioner

- Beregning af dansk skat
- Faneblade til forskellige beregninger
- Eksport til Excel og PDF via `xlsx` og `jsPDF`

## Kør

Åbn `index.html` i en browser. Der er ingen build eller server nødvendig.
